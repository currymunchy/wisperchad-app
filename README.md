# wisperChad

Free, private voice dictation for Windows. Hold a hotkey, talk, and clean text appears wherever you
type. It can write your replies too, and everything runs on your own PC.

**Website:** https://currymunchy.github.io/wisperchad-app/

**Download:** the latest installer is under [Releases](https://github.com/currymunchy/wisperchad-app/releases/latest).

**Support:** wisperChad is free. If it saves you time, you can [sponsor it on GitHub](https://github.com/sponsors/currymunchy).
