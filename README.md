# The wisperChad website

This repository holds the website for **[wisperChad](https://github.com/currymunchy/wisperchad)**, a free,
open-source voice dictation app for Windows and Mac that runs entirely on your computer. Hold a hotkey and
talk, and clean text appears wherever your cursor is. Hold the reply hotkey, say the gist, and wisperChad
writes a polished reply to the message on your screen.

**Live at [currymunchy.github.io/wisperchad-app](https://currymunchy.github.io/wisperchad-app/).**

## Looking for the app?

- **Download it:** [for Windows](https://github.com/currymunchy/wisperchad/releases/latest/download/wisperChad-Setup.exe)
  or [for Mac](https://github.com/currymunchy/wisperchad/releases/latest/download/wisperChad.dmg).
- **Read about it, report a problem or contribute:** [currymunchy/wisperchad](https://github.com/currymunchy/wisperchad).

## About this site

It's a single page, `index.html`, with no build step, served by GitHub Pages from the `main` branch.

- **Download buttons** link straight to the latest release in the
  [wisperchad](https://github.com/currymunchy/wisperchad/releases) repository, so a new release updates
  them with no change here.
- **The examples** type themselves out as you scroll to them.
- **Privacy:** the site has no analytics, cookies or trackers.

To preview it, open `index.html` in a browser, or serve the folder with any static server:

```bash
python -m http.server 8000
```
