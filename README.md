# wisperChad website

The website for [wisperChad](https://github.com/currymunchy/wisperchad): free, private voice dictation
and reply writing for Windows and Mac. Hold a hotkey, talk, and clean text appears wherever you type.

**Website:** https://currymunchy.github.io/wisperchad-app/

**Code and downloads:** [currymunchy/wisperchad](https://github.com/currymunchy/wisperchad). The website's
Download buttons fetch its latest release.

**Support:** wisperChad is free. If it saves you time, you can [buy me a coffee](https://buymeacoffee.com/phuasien) or [sponsor it on GitHub](https://github.com/sponsors/currymunchy).
